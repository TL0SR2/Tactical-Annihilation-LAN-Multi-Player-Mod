## 设计最优性说明（为何这是基线）

对本项目（注入式模组 + 回合制 + 复杂战斗/AI + LAN 可信）：

1. **Host 权威**优于锁步：避免改造全引擎确定性，AI/判胜/RNG 自然单点。  
2. **Intent/Command + Hash**优于逐步全量快照：带宽与结构更贴原版 API；快照仅作兜底。  
3. **P2 不开战 / M03 唯一闸**优于「先同步再补门禁」：从阶段上消灭双端抢操作。  
4. **MVP 含 M05 Strict**：否则无法验证 ADR-003；发行再切 Repair。  
5. **v1 砍重连/发现/热座**：降低状态机维度，先证明同步闭环。**Undo 保留**，须纳入 Host 同步而非禁用。  

若否定任一条 ADR，须 SUPERSEDED 而非局部改模块措辞。
